# nezer

Personal bio page: https://nezerkill.github.io/nezer/

One static `index.html` with hand-written CSS and vanilla JS, no build step. `stats.json` is refreshed once a day by the `stats` workflow: stars, commits in the last 30 days, followers, and the 30-day contribution strip. Icons are inlined as an SVG sprite, fonts come from Google Fonts, audio is served as Opus with an MP3 fallback.
